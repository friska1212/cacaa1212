## 📌 Project Utama

### 📊 Analisis Data Absensi via Telegram

Proyek ini bertujuan untuk mengumpulkan data absensi secara otomatis menggunakan bot Telegram sebagai bagian dari proses pengolahan data.

#### 🔧 Tools yang Digunakan:
- Python (Telegram Bot)
- Google Sheets *(dirancang sebagai penyimpanan data)*
- Google Looker Studio *(dirancang untuk visualisasi data)*

#### ⚙️ Cara Kerja Sistem:
1. Pengguna melakukan absensi melalui bot Telegram  
2. Data absensi (nama, NIS, waktu) dikumpulkan melalui bot  
3. Data dirancang untuk disimpan ke dalam Google Sheets  
4. Data kemudian dapat divisualisasikan menggunakan Looker Studio
